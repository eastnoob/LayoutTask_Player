## 第 2 项：强制 Pause 练习

用户决定：教程必须完成一次 Pause 练习。流程为点击 Pause、确认进入暂停；进入暂停后可等待倒计时自动恢复，也可点击 Resume 提前退出；两种退出方式都算完成该教程阶段。教程练习不消耗正式实验的一次暂停机会。教程阶段的 Pause 按钮高亮和黄色箭头在练习完成后立即移除，正式实验不显示。

用户决定：Pause 按钮使用高亮和黄色箭头同时引导。该高亮和箭头只服务于教程的 Pause 必做阶段；完成暂停练习后立即消失，正式实验中不保留。

用户决定：Pause 练习放在第一个物体保存之后、继续下一个物体之前。进入真实暂停并恢复（手动或自动）后该教程阶段才完成；未完成不能提交教程。

第 2 项核心交互已确认。暂停时阻止交互与提交、练习未完成不能绕过教程门槛，以及正式实验没有引导高亮或箭头，均纳入未来验收。

## 第 3 项：独立放大镜及强制练习

用户决定：选择 A，在教程及正式任务的平面图画布中隐藏原有 Zoom in、Zoom out、Reset view、Pan view 四个控件，改用放大镜观察细节。删除教程原有普通 zoom 说明，并使精炼后的文案与隐藏控件的决定一致。第 4 项家具参考板的拖动观察属于独立需求，不因主画布的 Pan 控件隐藏而取消。

进入时编辑状态保留、倍率范围与步长、镜片跟随鼠标及仅 ESC 退出已确认，详见下文。尚待明确镜片边界与提示布局、与 Pause 的互斥关系。

已澄清原话“对于画布本身的放大、缩小、还原、拖动，隐藏这个功能”：用户要求隐藏原有四个控件，不是添加第五个“隐藏”按钮。

用户决定：放大镜必做教程要求“进入放大镜 → 用滚轮调整至少一次倍率 → 按 ESC 退出”，三个动作全部完成后才能继续。仅进入模式不能算完成；进入模式期间禁止家具操作，镜片下显示 ESC 退出提示，后续文案精炼时保留这些信息。

用户决定：放大镜仅用于下方平面图，不作用于上方透视参考图；保持既有透视参考图观察限制。

用户决定：放大倍率范围为 1.5×–4×，默认 2×；滚轮每次调节 0.25×。镜片旁持续显示当前倍率，达到上下限时显示“最小 / 最大”提示。

用户决定：镜片跟随鼠标位置移动。进入放大镜模式后禁止点击家具、按钮或画布对象；用户只能移动镜片、用滚轮调节倍率，并按 ESC 退出。此处用户原话中的“被绿”按上下文理解为“倍率”。

用户决定：放大镜可随时启动，不要求先退出家具编辑。它是一个观察暂停层：进入时保留当前编辑状态和画面状态，放大镜期间冻结交互世界；退出后恢复进入前的原状态，不自动保存、重置或退出编辑。进入期间仍只允许移动镜片、滚轮调倍率和 ESC 退出。

用户决定：放大镜不提供退出按钮，只能按下 ESC 退出。镜片上在整个模式期间显著显示双语提示“按 ESC 退出放大镜 / Press ESC to exit”。

用户再次确认：仅 ESC 即可退出，退出提示必须在放大镜上显著展示；移动镜片和调节倍率时也持续可见。

用户决定：放大镜观察期间暂停有效实验计时；原始总时长保留。放大镜使用次数与总时长需单独记录，不与 Pause 合并。扣除放大镜后的时长也单独提供。

已观察事实：结果现有 `page_timing.player_elapsed_ms` 是从 player 启动到提交的墙钟时间；`active_player_elapsed_ms` 使用暂停控制器扣除 Pause；根级 `duration_ms` 同样扣除 Pause。因此沿用独立时间口径：保留原始墙钟时长；保留现有扣除 Pause 的 active 时长；新增放大镜使用次数与累计时长；新增 `active_player_elapsed_ms - magnifier_total_duration_ms` 的有效时长，单独扣除放大镜。正式 Pause 与放大镜不会合并成一个未区分的扣除量。

重要边界：原说明禁止放大透视参考图。新增放大镜保持只用于平面图，不改变该观察条件。

### 已确认规则合并后的教程顺序草案

1. 阅读说明并完成参考图观察/确认；已有知情同意、年龄和视力矫正信息流程保持不变。
2. 确认观察方向；黄色箭头只在教程确认前显示，确认后消失。

4. 放大镜强制练习：进入放大镜、滚轮调整一次倍率、按 ESC 退出。镜片持续显著显示“按 ESC 退出放大镜 / Press ESC to exit”。完成前不能进入第一个物体编辑。
5. 点击第一个带低调红光的黄色物体开始编辑。红光是常驻机制：当前任务中尚未完成首次保存的可编辑物体显示红光，完成保存后消失。
6. 调整位置和方向；实际移动或旋转不是完成门槛，但可按实验要求进行。
7. 选择位置和方向两个置信度。
8. 点击 Save，完成该物体的首次编辑记录；之后仍可无限次重新编辑。
9. 完成 Pause 强制练习：点击高亮 Pause，确认进入暂停；等待自动恢复或点击 Resume 均算完成。完成后高亮和黄色箭头立即消失，正式实验不显示。
10. 依次处理其他黄色物体；每个物体都必须至少完成一次编辑并保存位置、方向置信度。
11. 最后泡泡提示完成剩余物体并继续；Confirm 仍由现有提交门槛检查所有必答组。

## 正式设计第 3 段：计时字段与结果保存（已确认）

### 已观察事实

- `src/types/result.ts`、`src/schemas/result.schema.ts` 定义结果交换格式，当前为 `layouttask.result.v1`；放大镜字段尚不存在。
- `Recorder.finish()` 的 `duration_ms` 通过 Pause 控制器计算；`Recorder.recordEvent()` 的事件 `t` 也使用现有扣除 Pause 的时钟。

- `tools/decoder/decoder-utils.ts` 的 `validateTiming()` 当前将 `duration_ms` 与 `end_time - start_time` 直接比较；与 Recorder 已扣除 Pause 的口径不一致。本段计划包含对这一检查的校正，按当前任务时间窗口内真实 Pause 区间的重叠时长校验。

以上是源码观察；尚未执行本轮计时、编码或解码测试。

### 字段提议

| 字段 | 含义与兼容性 |
| --- | --- |
| `page_timing.total_elapsed_ms` | 保留现有页面墙钟总时间，可能包含入口阅读和其他阶段。 |
| `page_timing.player_elapsed_ms` | 保留现有当前任务墙钟时长，从 player 启动到提交；包含 Pause 和放大镜时间。 |
| `duration_ms`、`page_timing.active_player_elapsed_ms` | 保留现有扣除 Pause 的口径；不在这些旧字段中额外扣除放大镜。 |
| `magnifier.use_count` | 新增当前任务成功进入放大镜的次数。每次进入记一次；滚轮次数不作为使用次数。 |
| `magnifier.total_duration_ms` | 新增当前任务所有放大镜使用区间累计时长，单位毫秒。 |
| `effective_duration_ms` | 新增任务有效时长，即 `duration_ms - magnifier.total_duration_ms`。 |
| `page_timing.effective_player_elapsed_ms` | 启用 page timing 时提供相同的双重扣除口径，便于在同一 timing 结构中比较三种任务时长。 |

是否使用放大镜由 `magnifier.use_count > 0` 判定，不增加第二个可能与计数矛盾的 JSON 布尔字段。导出 CSV 时可提供派生的 `magnifier_used` 列。

### 统计与保存规则

- 进入模式成功才增加次数；未进入、重复点击、移动镜片或滚轮调节不会额外计次。即使立即 ESC 退出或教程练习未达标，真实使用仍计入次数和时长。
- 时长只扣除与当前任务起止窗口重叠的放大镜区间；Pause 和放大镜互斥，因此不会重复扣除。正常提交需先退出放大镜。
- 教程与正式题各自保存自己的放大镜摘要，不把教程练习累计进正式题。新题从零统计。
- 新结果未使用放大镜时明确保存 `{ use_count: 0, total_duration_ms: 0 }`；关闭 page timing 时仍保存根级摘要与 `effective_duration_ms`。
- 新字段与该任务现有答案保存在同一条结果中，进入现有编码、提交、备份和归档链路；不另建一份容易失去任务对应关系的计时文件。
- 保留 `layouttask.result.v1`，新增字段在 schema 中可选；历史结果缺少字段表示旧版未采集，不能当成“使用次数为零”。CSV 对旧结果填空，对新版未使用填零。
- 同步扩展 decoder 的结果解析、CSV 字段、空行模板和计时校验；保持原字段语义及旧数据可读取。旧版读取工具需要更新后才能展示新增信息。
- 操作事件的 `t` 沿用已有扣除 Pause 的时钟；新增有效时长用于独立分析，不把历史事件时间轴重新解释为已扣除放大镜。
- 只保存用户要求的次数与累计时长，不额外采集鼠标轨迹、逐帧镜片画面或每次倍率变化日志。使用区间在控制器内部用于正确计算时长。

示例：任务墙钟 120 秒、Pause 10 秒、放大镜累计 20 秒且使用 2 次，则原 `duration_ms` 为 110 秒，新 `effective_duration_ms` 为 90 秒，`magnifier` 保存次数 2 和时长 20000 毫秒。
